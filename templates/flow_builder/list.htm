Design guided conversation flows — a Start trigger, branching logic, menus, and prompts. An Agent flow is built here and then attached to one agent from that agent's settings; only Active agent flows that aren't attached elsewhere can be picked. A Generic flow is never attached to an agent: it is a child another flow runs with a Run Flow block, so a step you need in three places is drawn once. Making an attached flow a draft leaves it attached but stops the agent running it.
