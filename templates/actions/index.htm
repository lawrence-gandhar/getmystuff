Actions

An action lets an agent fetch live data from one of your own endpoints before it answers — an order status, an availability check, a ticket lookup. Define it once here and add it to as many agents as you like from each agent's Actions tab. Editing an action changes it everywhere it is used; deactivating one switches it off for every agent at once.
