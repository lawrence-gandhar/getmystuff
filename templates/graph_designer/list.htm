Graph Designer
Tool Graphs

Draw a flow of work on a canvas and run it. A node can be a SQL statement, a value (a list, an array or a dictionary), or an existing tool config; connect them and the run follows the chain you drew. You can branch, loop with For each or Do until, stop to ask a person mid-run, and end on a Success or a Failure node. Every node, or any group of them, can be tested on its own, with the flow, the state and a limited output shown below the canvas. Publishing a graph makes it callable, and Edit is where you say by whom: attach it to one data agent, or share it with a workspace so every agent in that workspace can call it — the Callable by column shows which it is. Publishing and an attachment are both needed, so a graph can be parked mid-edit without losing either — and a graph has one or the other, never both, because an agent cannot be given the same tool twice.
