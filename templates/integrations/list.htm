Connections {# Additive to a working non-AI surface, like every AI panel here: the New Workflow button beside it does the same job without a model involved. #}

Move records between the systems your business runs on. Draw a workflow on a canvas — read from one connection, map the fields, check them, and write to another — then run it by hand or on a schedule. Records travel a batch at a time, so a sync of fifty thousand is a hundred passes rather than fifty thousand. Publishing freezes the drawing as the version that runs, so editing a live workflow changes nothing until you publish again — and a run from last week still shows the workflow as it was then. A dry run builds every request and calls nobody, which is how you check a workflow against a real connection without writing anything anywhere.
