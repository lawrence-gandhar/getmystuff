The systems this application can talk to. Connecting one stores one set of credentials for one account — and you can connect the same app as many times as you have accounts: three Shopify stores are three connections, not a problem to work around. Credentials are encrypted before they are stored and are never sent back to a page, so an edit form starts empty and leaving it empty means "leave the stored one alone". Connecting an app does not move any data: it gives a workflow somewhere to read from and write to, and the workflow is what decides what travels where.
