How this prompt is used
{% if key.target_type == "agent" %}

Every visitor message is answered with this prompt, and data questions are answered by running the attached data agent's tools. This widget has no data source of its own, so the agent below is what it reads — changing it changes what the widget can answer.

Two rules are always appended and cannot be overridden by the prompt: answers may only use figures a tool returned, and the assistant must say so when no tool covers the question. If the agent can't run, the widget says it can't reach the data rather than guessing — there is no data profile to fall back on.

{% else %}

Every visitor message is answered with this prompt, the chatbot's data scope ({{ key.target_type }}), and a statistical profile computed from your real data.

Two rules are always appended and cannot be overridden by the prompt: answers may only use figures from that profile, and the assistant must say so when the data doesn't cover the question.

{% endif %}

A saved prompt is rejected if it references a variable you haven't defined — so a live chatbot never sends a half-filled prompt to the model.
