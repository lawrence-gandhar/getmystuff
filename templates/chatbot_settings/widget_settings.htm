widget.js is a generic, static file — the same download works for every chatbot. Paste this snippet into your site before the widget script tag so it knows which chatbot and backend to talk to, then download the widget file below and host it at the referenced path. Editing settings below updates the live widget immediately — no re-download needed.

apiBase must match the scheme of the page you embed on. A page served over https:// cannot call an http:// address — the browser blocks it before the request is sent and reports it as a CORS error, and the widget quietly falls back to its default appearance. If the API answers on the same origin as your page, drop the apiBase line entirely and every request becomes relative. Either way, add the page's own origin to Allowed Domains, and check the browser console — the widget names the exact request and reason whenever it cannot reach the API. 
<script>
  window.GMSChatbotConfig = {
    apiBase: "{{ api_base_url }}",
    apiKey: "{{ key.api_key }}"
  };
</script>
<script src="widget.js"></script>
