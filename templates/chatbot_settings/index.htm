Each agent is one embeddable chat widget, scoped to a whole datasource or to one or more tables, collections, or files within it. Give it a prompt and a language model in its settings, add shared actions, and attach a flow when the conversation should follow fixed steps. Because an agent's key ends up inside a downloadable JS file anyone can view, it's a publishable key, not a secret — access is restricted by the datasource it's scoped to and the allowed domains you set, not by hiding the key itself.
