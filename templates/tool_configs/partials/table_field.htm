Replaced wholesale (hx-swap="outerHTML") whenever the datasource changes, so its options are always the objects that really exist in the selected datasource — tables, collections or files, depending on its type. A **multi-select**: a query over more than one table is the ordinary case in both modes. The first selection is the primary table — the base table a built query's joins hang off and its bare column references mean — and the order the browser posts is document order, which is why the option list is what fixes it rather than the order the user clicked in. Picking tables cascades once more, into the query builder, so the column dropdowns offer those tables' real fields and the Joins card offers exactly the tables named here. #}
