How this agent answers

The language model is never given your data. It sees your instructions, the tool descriptions above, and the rows a tool returns when it calls one — nothing else, and no connection of its own.

Each tool runs a fixed query saved in Tool Configs and takes no arguments, so the model chooses which tool to call, never what it queries.

{# The paragraph above stops being the whole truth once a source is marked Filterable, and saying only the first half is what leaves an operator unable to explain why the agent refused to filter by month. The query is still fixed; what changed is that the records it returns can be narrowed afterwards. #} {% if agent.has_readable_tools %}

A source marked Filterable is the exception worth knowing: its query is still fixed, but the model may ask for every record it returns to be read and then narrowed or totalled — one month, one department, a total per group. So it can answer conditions the query itself takes no parameter for.
