How this agent answers

The language model is never given your data. It sees your instructions, the tool descriptions above, and the rows a tool returns when it calls one — nothing else, and no connection of its own.

Each tool runs a fixed query saved in Tool Configs and takes no arguments, so the model chooses which tool to call, never what it queries.

Every answer below lists the tools it called. An answer with figures and no tool call would mean the model invented them.
