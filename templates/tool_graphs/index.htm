Tool Graphs
{# The way out of a read-only page. This one draws graphs it derives from tool configs; the Designer is where a graph is authored and run. #} Design a Graph

Every tool config drawn as what it actually is. Tool Graph is the chain a nested tool compiles to — the inner tools run first, left to right, and their values restrict the one that follows. SQL Graph is the same tools' joins as the sets they intersect. Nothing on this page can be edited: pick a tool in Tool Configs to change it, or open the Graph Designer to draw and run a graph of your own.
